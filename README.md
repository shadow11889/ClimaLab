# ClimaLab — Simulações Climáticas e Monitoramento Ambiental

## Arquivos
- index.html — página inicial
- graficos.html — gráficos e projeções
- contador.html — contador de emissões CO₂e
- carbono.html — simulador de créditos de carbono
- sobre.html — informações do projeto
- css/climalab.css — identidade visual compartilhada
- js/climalab.js — navegação comum

## Uso
Abra `index.html` no navegador. Não é necessário servidor para a versão básica.
